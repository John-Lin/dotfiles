# Omarchy 3 configs (archive)

These are the pre-4.0 Hyprland configs, in the `.conf` format Omarchy used
before it moved to Lua. **Nothing here is installable.** They are kept only as
a record of what the old setup was, so a 4.x regression can be checked against
what used to work.

See `../MIGRATION-4.0.md` for how each of these was ported, and which settings
were deliberately dropped in favour of Omarchy 4 defaults.

`hypridle.conf` and `hyprlock.conf` are doubly obsolete: those packages no
longer exist in 4.0, and their behaviour moved into the Quickshell shell
(`~/.config/omarchy/shell.json`).

Delete this whole directory once Omarchy 4.x has proven stable in daily use.
